# 🏥 Healthcare Management Data Analysis using SQL

A SQL data analysis project that explores a healthcare dataset to uncover meaningful insights about patients, doctors, hospitals, billing, insurance providers, and medical conditions using **Microsoft SQL Server (SSMS)**.

This project demonstrates practical SQL skills by solving real-world business questions through data exploration, aggregation, and analytical queries.

---

## 📌 Project Overview

The primary objective of this project is to analyze healthcare data and generate actionable insights using SQL. The project covers various aspects of healthcare management, including patient demographics, doctor performance, hospital performance, billing analysis, insurance usage, and admission trends.

The project is designed as a portfolio project for aspiring Data Analysts to demonstrate proficiency in SQL.

---

## 📊 Analysis Performed

The project is organized into the following sections:

### 1️⃣ Database Exploration

* Database creation
* Table exploration
* Dataset structure analysis

### 2️⃣ Patient Analysis

* Total patient records
* Gender distribution
* Average patient age
* Youngest and oldest patients
* Blood group distribution
* Patients grouped by age category
* Average age by gender

### 3️⃣ Doctor Analysis

* Total number of doctors
* Patients treated by each doctor
* Top 10 busiest doctors
* Average billing generated by each doctor

### 4️⃣ Hospital Analysis

* Total hospitals
* Top hospitals by patient count
* Top hospitals by revenue
* Hospitals with negative revenue

### 5️⃣ Medical Condition Analysis

* Disease distribution
* Average billing by disease
* Average patient age by disease
* Disease distribution by gender

### 6️⃣ Billing Analysis

* Total revenue
* Average billing amount
* Highest and lowest billing amount
* Top 10 highest billing patients

### 7️⃣ Insurance Analysis

* Patients by insurance provider
* Most frequently used insurance provider

### 8️⃣ Blood Group Analysis

* Blood group distribution
* Most common blood group

### 9️⃣ Date Analysis

* Yearly admissions
* Monthly admissions
* Yearly revenue trend

### 🔟 Advanced SQL Analysis

* Running total of yearly revenue using Window Functions
* Patient health status categorization using CASE statements
* Rank Hospitals by Revenue
